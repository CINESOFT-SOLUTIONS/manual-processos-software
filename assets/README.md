# 🖼️ Artefatos Visuais e Diagramas (assets)

Esta pasta destina-se ao armazenamento de diagramas, fluxogramas, esquemas arquiteturais e modelos de processo (BPMN, PlantUML, SVG, PNG e PDF) utilizados no Manual de Processos de Software.

---

## 📌 Padrão de Organização

- **Fontes PlantUML / BPMN:** arquivos `.puml` ou `.bpmn`.
- **Exportações Vetoriais:** arquivos `.svg` e `.pdf` (usados para inclusão no LaTeX e no Markdown).
- **Imagens Gerais:** `.png` em alta resolução.
