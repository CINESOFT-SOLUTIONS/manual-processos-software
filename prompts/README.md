# 🤖 Catálogo e Engenharia de Prompts (prompts)

Esta pasta reúne os templates de prompts e os artefatos de validação técnica utilizados com IA no desenvolvimento do **Manual de Processos de Software**.

---

## 🗂️ Estrutura

```text
prompts/
├── README.md
├── templates/
│   └── template-prompt.md          # Template padrão para novos prompts
└── validacoes/
    ├── validador-iso12207.md       # Prompt estruturado para validação normativa contra a ISO 12207
    └── analise-ia-parte-03.md      # Relatório de auditoria e correção da sugestão de IA da Parte 3
```

---

## 📌 Guia de Uso

- **`templates/`**: Utilize o [`template-prompt.md`](templates/template-prompt.md) ao redigir prompts para novas partes do trabalho.
- **`validacoes/`**: Contém o [`validador-iso12207.md`](validacoes/validador-iso12207.md) para checagens de aderência da IA e o histórico de auditorias normativas.
